База: ветка `grok/finish-pass` (этапы ветвить после её мержа в main).

## Приоритет 1 — Взаимодействия стихий (система синергий)

**Статус:** есть один хардкод-пример — «Скрещивание лучей: Резонансная Сверхновая»
(`AetheriaSpellActors.cpp`, `SetSynergyBanner`). Системной таблицы нет.

**Сделать:**
- Таблица синергий данными (не if-ами): метка-источник → триггер → эффект → баннер.
- 6–8 базовых взаимодействий:
  - BlackHole (метка втягивания) → Sun Strike = детонация зоны;
  - Chronosphere → летящие вражеские снаряды замораживаются в сфере;
  - ChaosMeteor → PrismWall = осколочный взрыв при проходе;
  - ChainLightning → Macropyre = подожжённая цепь (DoT-разгон);
  - PlasmaField → BlackHole = двойное втягивание (радиус и длительность ↑);
  - EyeOfTheStorm → PrismWall = турбулентность (отталкивание от стены).
- Переиспользовать существующий `SetSynergyBanner` (RU-текст уже в стиле HUD).

**Критерий:** `-GrokCombatTest` проверяет ≥2 синергии; каждая — видимый эффект + звук + баннер.

## Приоритет 2 — Реликвии + эссенс-экономика

**Статус:** реализовано 5 реликвий с бонусами (`ember_heart`, `chrono_astrolabe`,
`singularity_seal`, `prism_monocle`, `archon_crown` — `AetheriaWizardCharacter::GrantRelicBonus`),
редкости, дроп с RU-баннером и звуком. Arcane Essence копится, **трат нет**.

**Сделать:**
- Расширить до 10–12 реликвий; минимум 3 новые завязать на синергии из П1
  («метки живут +50%», «синергии +40% урона», «синергия не расходует кулдаун-ресурс»).
- Алтарь в Святилище — стоки эссенса: перековка редкости реликвии, +ранг Empower.
- Проверить сохранение `OwnedRelicIds` в `UAetheriaSaveGame` (сейчас в сейве только
  `EquippedRelicNames`).

**Критерий:** за 30-минутную сессию игрок 2–3 раза осознанно тратит эссенс.

## Приоритет 3 — Полиш босса Аркона

**Статус:** фазы есть (`BossPhase`, `LastTriggeredBossPhase`, SFX_Phase_Transition,
sig-атаки CryoTide/Magma/VoidStorm, телеграф-звук `SFX_Boss_Telegraph`).

**Сделать:**
- Визуальные телеграфы AoE: декали/световые кольца на полу (читаемость без звука).
- 3-я фаза: смена арены — затемнение неба, обрушение декора, плотнее паттерн.
- Смерть босса: slow-mo + разлёт осколков + существующий `SFX_Boss_Death`.

**Критерий:** паттерны читаются на скриншотах без звука (проверка кадрами `-GrokWorldShot`).

## Приоритет 4 — Петля смерти / биконы

**Статус:** респавн есть (`RespawnTimer = 12с` в GameMode), **экрана смерти нет**;
биконы и capture-SFX есть в GameMode/BiomeBuilder.

**Сделать:**
- Экран смерти в SlateHUD: затемнение, «Ты павший…», таймер, потеря 10% несобранного
  эссенса (мягкий штраф, не фрустрация).
- Бикон-петля: захват → 2 защитные волны → награда (эссенс + шанс реликвии).
  Бой ~90–120 с, между основными маршрутами.

**Критерий:** смерть даёт понятный откат; бикон-бой — самодостаточный эпизод.

## Этап 2 — Paragon-боссы (Dark Souls-петля)

**Статус:** запланировано. **Старт — только после релиза демо v1.**

Идея: в Fab/проекте уже импортированы Paragon-модели (Gideon уже привязан как герой).
Новых боссов собираем из них — с собственными анимациями, эффектами и характером,
чтобы бой ощущался как Dark Souls: увороты, окна на удары, телеграфы, хил.

### Шаг 0 — Инвентаризация контента (первое действие этапа)
- Ревизия импортированных Paragon-паков: какие модели имеют полный комплект
  меш + скелет + анимации. Выбрать 2–3 кандидатуры на боссов.
- Конвейер переиспользуем: у собственных персонажей уже есть по ~7–8
  реитаргетнутых монтажей — тот же путь для боссов.

### Боссовый контент (на каждого босса)
- Свой набор монтажей + 2–3 фирменные атаки по образцу sig-атак Аркона
  (CryoTide/Magma/VoidStorm), каждая с уникальной механикой уклонения.
- Фазы через существующие `BossPhase` / `LastTriggeredBossPhase` (2–3 фазы,
  усиление паттерна на каждой).
- Видимые телеграфы AoE: декали/световые кольца на полу (читаемость без звука).
- Боссовый HP-бар + имя в SlateHUD, интро-появление (имя + рывок камеры),
  смерть со slow-mo.

### Soulslike-кит игрока (закрытие гэпов)
- **Уворот с i-frames**: dash уже есть — расширить окном неуязвимости и
  отдельным звук/шейк-фидбеком.
- **Фласка хила**: ограниченные заряды, пополнение в Святилище; хил с анимацией
  и уязвимостью во время питья (окно риска).
- **Lock-on камера**: фиксация на боссе, круговое стрейф-движение.
- **Стамина** — опционально, только если увороты без неё становятся бесплатными.

### Эффекты
- Переиспользовать hovl/yuki VFX-паки и хелперы `AetheriaPackVFX`;
  боссовые SFX по существующей схеме `SFX_Boss_*`.

**Критерий этапа:** бой 1v1 с боссом ~3–5 минут, смерть игрока — из-за нечитанного
паттерна, а не из-за несправедливости; после победы — ощутимая награда (реликвия).

## Порядок работ

**Демо v1:** мерж finish-pass → П1 → П2 → П3 → П4 → тесты → пакедж → релиз демо.
Каждый приоритет — отдельная ветка от актуального `main`; перед этапом — прогон
`Scripts/run_ground_tests.sh`.

**После демо v1:** Этап 2 (Paragon-боссы, Dark Souls-петля) — начинается с
инвентаризации Paragon-контента (Шаг 0 этапа). До релиза демо инвентаризацию не делаем.
Этот документ — untracked-файл, текущей работе на `grok/finish-pass` не мешает.
